# Instruções do projeto

- Mantenha documentação relevante em `docs/`.
- Atualize o `README.md` quando comandos, configuração ou uso do projeto mudarem.
- Ao concluir uma tarefa, registre as mudanças necessárias, crie um commit descritivo e envie-o para o remoto configurado, salvo orientação contrária do solicitante.

@RTK.md
Após concluir esta alteração, faça um git add, git commit com uma mensagem clara e 
descritiva sobre o que foi feito, e git push para o repositório remoto no GitHub. 
Não pergunte confirmação, apenas faça o commit e push automaticamente ao final de 
cada tarefa concluída.

Documente esta alteração na pasta docs/: adicione uma entrada em docs/CHANGELOG.md 
descrevendo o que foi feito e quando, e atualize os arquivos relevantes 
(docs/arquitetura.md, docs/schemas-sanity.md ou docs/paginas.md) caso a estrutura, 
os schemas do Sanity ou as páginas tenham mudado. Atualize também o README.md.
